# 第四阶段开发记录

## 4.1 待办与基础日程、4.2 每日记录

- 复用 V2 现有表及字段，保留 `/planner` 和「待办 / 日程 / 日记」三个标签。新增共享日期选择和当天概览，按日期展示到期待办、相关日程及日记。
- 待办支持新增、编辑、软删除、完成与恢复未完成；标题、描述、优先级、截止日期与可选时间，以及状态/日期筛选和排序。
- 单次日程支持新增、编辑、确认后删除；支持全天、起止时间及结束时间校验。跨日定时日程在与其时间段相交的本地日期显示。
- 日记支持可选标题、非空正文、选择日期、新增编辑、确认删除、同日多条、按日期或标题/正文搜索。
- 纯日期保留 `YYYY-MM-DD`；具体时间使用本地时间输入，转成 UTC 毫秒保存，展示时转换为设备本地时间。全天日程不保存具体时刻。切换设备时区与夏令时场景仍需设备测试。
- V2 的日程及日记表无软删除字段，确认删除后无法恢复；待办采用已有软删除字段。没有升级 schemaVersion，也没有清空数据库。
- 不实现重复任务、通知调度、图片、同步或 AI；这些功能留待后续阶段。
- 数据库分页、跨月统计自动刷新及大数据量和交易边界测试仍为第三阶段待办。
